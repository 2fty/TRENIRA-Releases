# TRENIRA — официальные APK-обновления

Публичный репозиторий **подписанных APK** Android-приложения TRENIRA.

**Исходный код и ключи подписи не публикуются:** они хранятся отдельно в закрытом проекте. Здесь находятся только готовые APK, контрольные суммы и описания версий.

## Как обновляться

Установи TRENIRA 0.7.3 или новее, затем открой **Профиль → Обновления приложения**. Приложение проверит доступность новой версии, скачает APK и попросит подтвердить установку через Android.

До установки обновлятор сверяет SHA-256 и номер пакета. Android проверяет цифровую подпись. Данные тренировок остаются на устройстве.

## Выпуски

Используй раздел **Releases**, а не временные артефакты GitHub Actions. Каждый релиз имеет тег `vX.Y.Z`, файл `TRENIRA-X.Y.Z.apk` и описание с полем `versionCode: N`.

> Если в разделе Releases пока нет выпусков, публикация ещё не была настроена в закрытом проекте.
